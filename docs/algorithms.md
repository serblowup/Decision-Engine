# Алгоритмы оптимизации сегментации VLAN

## Постановка задачи
Рассматривается взвешенный граф трафика `G = (V, E, W)`, где `V` — множество сетевых устройств (хостов), `E` — каналы взаимодействия, `W` — матрица весов (`w_ij` равен объему трафика между устройствами `i` и `j`). Требуется найти разбиение `S` устройств по VLAN, максимизирующее целевую функцию:

`F(S) = T_intra(S) - λ * T_inter(S) - μ * P_constraints(S)`

где:
- `T_intra(S)` — суммарный внутрисегментный трафик,
- `T_inter(S)` — суммарный межсегментный трафик,
- `P_constraints(S)` — штраф за нарушения ограничений,
- `λ` (по умолчанию `0.5`) и `μ` (по умолчанию `1.0`) — коэффициенты регуляризации.

Задача NP-hard (редуцируется к задачам graph cut/min-cut с ограничениями), поэтому в модуле применяются эвристические методы, обеспечивающие практическое качество решения при ограниченном времени.

## Алгоритм 1: Greedy Merge/Split
Жадный алгоритм выполняет локальные операции слияния и разделения сегментов, выбирая действие с максимальным приростом цели.

Формулы локального выигрыша:
- `delta_merge = 2 * W(S_i, S_j) - λ * (W(S_i, S_i) + W(S_j, S_j))`
- `delta_split = λ * W(A, B) - W(A, A) - W(B, B)`

Ссылка: Kernighan B.W., Lin S., 1970.

## Алгоритм 2: Spectral Clustering
Метод строит нормализованный лапласиан графа:

`L = D^(-1/2) * (D - W) * D^(-1/2)`

и использует спектр `L` для поиска структуры кластеров по критерию Normalized Cut:

`NCut(S) = Σ_i cut(S_i, V \ S_i) / vol(S_i)`

Теорема Фидлера связывает второй собственный вектор с оптимальным бинарным разделением; для `k` кластеров используются `k` наименьших ненулевых собственных векторов.

Ссылки: Shi-Malik (2000), Ng-Jordan-Weiss (2002).

## Алгоритм 3: Simulated Annealing
Алгоритм использует стохастический поиск с температурой:

`T(t) = T0 * α^t`, `α ∈ [0.85, 0.99]`

Вероятность принять ухудшающий ход:

`P = exp(delta_F / T)`, где `delta_F <= 0`.

При высокой температуре обеспечивается исследование пространства, при низкой — локальная донастройка решения.

Ссылка: Kirkpatrick et al., 1983.

## Сравнительный анализ

| Алгоритм | Качество | Скорость | Детерминированность | Гарантии сходимости | Рекомендация |
|---|---|---|---|---|---|
| Greedy Merge/Split | Среднее/высокое на простых графах | Высокая | Высокая | Локальный оптимум | До ~20-50 устройств, low-latency |
| Spectral Clustering | Высокое при явных кластерах | Средняя | Высокая при фикс. seed | Завязано на спектральную структуру | 50+ устройств и выраженные кластеры |
| Simulated Annealing | Потенциально высокое на сложных графах | Низкая/средняя | Средняя | Теоретически глобальный оптимум при лог-охлаждении | Сложные графы, quality-first сценарии |

Практический выбор:
- Если нужен быстрый ответ в real-time: `greedy`.
- Если важна структура кластеров и устойчивость: `spectral`.
- Если допускается больше времени ради лучшего глобального решения: `sa`.
